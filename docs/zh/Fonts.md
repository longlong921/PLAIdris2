# Fonts · 字体

证明中的字体会影响理解，因为外观相近的符号可能表示不同操作。Idris 实现使用普通 ASCII 标识符；正文有时使用 `λ`、`→`、`∀`、`∃`、`⊑` 等数学 Unicode。若显示字体让两个字符难以区分，请以源码为准。

## 在你的设备上阅读 {#fonts}

站点正文使用系统 UI 字体；代码依次尝试本地 Iosevka、JetBrains Mono、DejaVu Sans Mono、Liberation Mono，最后退回浏览器等宽字体。中文使用已安装的 CJK 字体回退。站点不访问字体服务、不附带字体二进制，也不要求购买字体。

若某个字符显示为空方框，可以安装具有对应 Unicode 字形的本地字体，或修改浏览器默认字体。若连字使 `->` 看起来像单个箭头，记住源码仍含有两个 ASCII 字符。需要精确复制时，请下载源码。

## 正文符号约定 {#symbols}

| 显示 | 读法 | 用途 |
| --- | --- | --- |
| `A → B` | 从 A 到 B 的函数 | 依定义表示宿主函数或对象箭头类型 |
| `M —→ N` | M 一步归约为 N | 归纳定义的关系 |
| `M —↠ N` | 零步或多步归约 | 自反传递闭包 |
| `Γ ⊢ M : A` | 在 Γ 中 M 的类型为 A | 类型判断 |
| `v ⊑ w` | v 的信息不多于 w | 第 3 部分的信息预序 |
| `⊥` | 没有有限信息 | 一个语义值，不是异常 |

宿主函数箭头与对象语言归约箭头的区别是数学上的，不只是外观不同。依赖符号前，先读其周围的定义。[Equality](Equality.md)还会区分定义计算与显式的相等证明。

## 可访问性 {#accessibility}

放大文字后仍可使用章节导航。宽代码块只在局部滚动，移动版菜单有键盘可操作的按钮，页首提供跳到正文的链接。样式表遵循减少动态效果的系统偏好，并提供打印布局。语言切换保留共同节锚点，便于对照讲解，而不必再次寻找所在位置。
