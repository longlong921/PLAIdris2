# Naturals：从构造子认识自然数 {#naturals}

## 为什么学习这一章 {#motivation}

证明助手不必把算术当作无需解释的事实。我们可以先说明自然数如何构造，再按照这种构造定义运算，最后让类型检查器核对计算结果。本章从这个小基础出发。后续章节会用同样的方法证明关于所有自然数、最终关于所有程序的性质。

我们使用 Idris 的 `Nat`，它的构造子是 `Z` 和 `S`。`Z` 表示零，`S n` 表示 `n` 的后继。因此二就是 `S (S Z)`。这些值是有限的构造树：不断取前驱，最终到达 `Z`。这里没有负数构造子，没有最大的构造树，也没有表示无穷大的额外构造子。所以，一个有限的定义可以描述无限多种有限值。

## 定义模型 {#model}

类型 `Nat -> Nat -> Nat` 描述一个柯里化函数：先接收一个自然数，再返回一个接收自然数的函数。函数应用向左结合，所以 `add m n` 表示 `(add m) n`。我们给各个运算单独命名，使定义方程清晰可见；它们并不是对算术求解器的调用。

{{include:src/PLFA/Part1/Naturals.idr#arithmetic}}

加法对**第一个**参数递归。零不贡献任何东西；一个后继贡献一个 `S`，并留下更小的加法。乘法同样在第一个参数每减少一个后继时，加上一份第二个参数。乘方对指数递归，零指数的结果为一，即使底数也是零。这是自然数乘方通常采用的代数约定。

这里的减法叫作截断减法（monus）：减到零就停止。减去零保持原数；从零减去后继仍为零；两边都有后继时各消去一个。每次递归都会消耗构造子，所以这些定义满足 `%default total`。

## 逐步计算 {#examples}

计算 `add 2 3` 时，先把二看成后继。结果依次变成 `S (add 1 3)`、`S (S (add 0 3))`，最后得到 `S (S 3)`，也就是五。`mul 2 3` 变成 `add 3 (mul 1 3)`，最终得到两份三。`monus 3 5` 消去三对后继后，左边已经为零，右边还要求再减两次，因此结果为零。

每个例子的类型都是一个命题。`Refl` 证明：按照定义计算后，两边相等。显式写出的七说明了数字字面量如何简写构造子。这些例子检查定义的行为；检查若干输入，还不是证明关于所有输入的定律。

## 二进制表示 {#binary}

一元构造子便于归纳，但大数需要许多个后继。二进制每追加一位，就把前缀表示的数翻倍；追加一时再加一。`B0 b` 给位串 `b` 追加零；最外层构造子对应最右边的最低位。例如十一是 `B1 (B1 (B0 (B1 Empty)))`：从内向外读，得到 1011。

{{include:src/PLFA/Part1/Naturals.idr#binary}}

末位为零时，加一把它改成一；末位为一时，改成零并向前缀进位；到达空前缀时，进位创建一个一。`toBin` 从单独的一位零开始，反复加一；`fromBin` 用翻倍规则解释各位。`binaryExamples`、`binaryValues` 和 `carryExample` 检查零到四，以及十一加一得到十二的进位。

`Empty`、`B0 Empty` 和 `B0 (B0 Empty)` 的数值都是零。原始数据类型有意允许前导零。`normalize` 通过转换到 `Nat` 再转换回来，选择一个表示。这种转换是简单的规格说明，并没有声称适合高效处理大数：反复加一仍沿着一元输入递归。

## 已经证明了什么 {#theorems}

本章所有展示的例子都是由计算检查的封闭等式。下一章将证明：加一使解释后的数值增加一；任意自然数转换到二进制再转回，都是原数。反方向的往返需要限制表示形式，[Relations](Relations.md#canonical) 会给出这个限制。区分这两个命题，可以避免因为几个测试通过，就误信一个错误定理。

## 容易混淆的地方 {#pitfalls}

`Refl` 不会自动使用交换律。`add 0 n` 能计算为 `n`，但当 `n` 未知时，`add n 0` 无法继续，因为加法检查第一个参数。截断减法不是整数减法：`monus 3 5` 为零，不是负二。二进制的嵌套方向与打印出来的位序相反。另外，空位串和规定的零表示虽然数值相同，却是不同的语法值。

## 习题与已检查解答 {#exercises}

1. **N.1 — 构造子。** 不使用数字字面量写出七。参考 examples 区域中的 `seven`。
2. **N.2 — 化简。** 计算三加四和三乘四，逐步写明使用了哪条定义方程。已检查的终点是 `addExample` 和 `mulExample`。
3. **N.3 — 指数。** 对指数递归定义乘方，检查三的四次方。参考 `power`、`powerExample`，并解释为什么零指数的结果为一。
4. **N.4 — 截断减法。** 计算三减五与五减三。参考 `monusExample`；两个结果体现了截断规则。
5. **N.5 — 进位与转换。** 实现加一与双向转换，检查最小的五个数和十一的后继。参考 `inc`、`toBin`、`fromBin`、`binaryExamples`、`binaryValues`、`carryExample`。

以上解答直接包含自已编译源码。建议先尝试，再查看对应定义。可以在本地故意改错一个数值结果后重新检查：错误等式应当被拒绝。
