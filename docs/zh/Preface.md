# Preface · 前言

想象一个只有函数和自然数的小语言。求值器可以执行表达式，类型检查器可以拒绝某些表达式。但这两件事都不能单独说明：执行过程是否保持类型？要把它们连接起来，需要精确的定义和证明。这正是本书希望培养的习惯。

## 你将学到什么 {#learning}

第 1 部分建立表达证明的语言：数据、归纳、关系、相等、逻辑联结词、量词与判定。第 2 部分用这些工具定义程序语言，并推理其执行过程。第 3 部分换一个问题：能否不给出一串执行步骤，就为程序项赋予数学含义？最后，我们把这种含义与周围程序能够观察到的行为连接起来。

章节严格遵循冻结版本的 [PLFA 目录](https://github.com/plfa/plfa.github.io/blob/1c39b1e82caa4283274e64ba58c3bc3c9ab781eb/data/tableOfContents.yml)：三章前置内容、十章逻辑基础、九章操作语义、五章指称语义、替换附录，以及两章后记内容。Idris2 语法、数量类型和可信边界集中放在独立扩展区；你可以随时查阅，而不改变主线顺序。

## 如何阅读经过检查的证明 {#reading}

先读定理的类型，再读实现。区分哪些输入是普通数据，哪些输入是证据。然后问：递归调用时，哪项输入变小了？关于所有自然数的证明可以对数归纳；关于所有归约的证明可以对归约推导归纳。这是两种不同的归纳。

运行例子前，先手算一次。证明很短时，不要因此跳过讲解：一行构造子可能包含了类型检查器作出的好几个选择。证明较长时，可以把具名引理当作路标。每段引用代码上方的链接都能打开完整源码。

每个技术章节都有习题与参考解答。建议先尝试，再查看解答符号。通过构建的参考实现没有未完成的练习洞。负向测试单独存放，因为它们的职责就是失败：证明检查器应当既能接受正确证明，也能可靠地拒绝错误证明。

## 两种语言，一套推导 {#languages}

中英文章节使用相同的定义、定理前提、习题编号、源码引用与节标识。语言按钮会进入对应章节，并携带当前锚点。翻译后的标题可以换一种自然表达，数学命题却不能改变。

本书面向已经熟悉函数、递归和初等代数的读者，不要求预先掌握 Agda。第 3 部分有些证明确实需要耐心；困难来自高阶计算、替换和有限信息，而不是要求你背诵简短语法。遇到一个引理时，可以停下来分析最小的情形，再回到需要它的定理。

## 本书的“已检查”意味着什么 {#checked}

参考定义与证明由锁定的 Idris2 0.8.0 检查，并要求总性。这些证据依赖宿主编译器及其依赖类型实现，并不是对 Idris2 本身作为基础逻辑的一致性证明。尤其是，它的宇宙实现使用 `Type : Type`。[可信边界扩展](Trust.md)会说明这个边界，以及我们实际执行的检查。

对象语言与宿主语言是两回事。无类型 lambda 项可能发散。对有限推导进行分析的总函数，或只执行有限燃料的总函数，都不能使所有对象程序终止。同样，合流性说明两条有限归约路径能够重新汇合，并不保证每个项都有正规形。
