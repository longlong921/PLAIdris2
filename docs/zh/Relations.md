# Relations：由数值索引的关系证据 {#relations}

## 为什么需要关系 {#motivation}

布尔比较能告诉我们二不大于四。关系还可以返回一棵有限推导树，说明**为什么**成立。我们可以检查和转换这样的证据，再把它交给其他定理。这是第一个较完整的索引数据类型例子：索引记录每个构造子所证明的判断。

## 定义模型 {#model}

`LE m n` 表示 `m` 不大于 `n`。`LZ` 证明零不大于任何自然数；`LS` 把 `m ≤ n` 的证据变成 `S m ≤ S n` 的证据。推导的类型排除了不可能的形状。例如，二不大于四的证据一定先有两个 `LS`；任何构造子都无法证明后继不大于零。

{{include:src/PLFA/Part1/Relations.idr#order}}

`lePred` 是反演：从两端都是后继的索引结论中，取出它的前提。`leZero` 说明不大于零的数只能等于零。花括号表示隐式参数；其中有些显式保留为可用参数，因为产生证明的函数需要检查它们。Idris 中被擦除的参数即使在类型里有名字，也不能拿来进行运行时计算。

## 阅读一个序关系证明 {#examples}

`twoLEfour` 是 `LS (LS LZ)`。最内层规则证明零不大于二；第一个后继得到一不大于三；第二个后继得到二不大于四。证明传递性时，要检查两份推导。第一份若是 `LZ`，结果直接为 `LZ`；若是 `LS`，共同的中间索引会迫使第二份也以 `LS` 开始。剥掉两边的后继，递归，再恢复一个后继。

反对称性采用类似结构，但最后得到等式。可比性则不同：对任意两个自然数，产生 `LE m n` 或 `LE n m`。这不表示二者互斥；相等的值同时满足二者。`Trichotomy` 将严格顺序与相等分开。这里定义 `LT m n = LE (S m) n`，所以它与后继形式之间的转换是定义上的相同，而不必另设一对构造子。

## 顺序与奇偶定理 {#theorems}

order 区域证明自反性、传递性、反对称性、可比性、加法和乘法单调性、严格传递性、严格加法单调性及非自反性。`addMono` 允许两个参数都增加；`ltAddMono` 证明两者都严格增加时，和也严格增加。`leStep` 与 `ltToLe` 连接严格和非严格的界。这些命题适用于任意自然数及推导。

{{include:src/PLFA/Part1/Relations.idr#parity}}

奇偶性是互相定义的：零为偶数，奇数的后继为偶数，偶数的后继为奇数。`fourEven` 交替使用构造子，直到零。“偶数加偶数为偶数”和“奇数加偶数为奇数”的证明也互相递归：剥掉最外层构造子后，需要调用另一条奇偶定理。另一组证明偶数加奇数为奇数、奇数加奇数为偶数。每次调用都消耗第一棵证据树的一部分，因此互相递归仍然终止。

## 规范二进制位串 {#canonical}

{{include:src/PLFA/Part1/Relations.idr#canonical}}

`One b` 表示首位为一。它从且仅从 `B1 Empty` 开始，随后允许追加零或一。`Canonical b` 允许这样的正数位串，或者单独的一位零。这个谓词没有允许前导零的构造子。原始位串类型仍不受限制；谓词在其中辨认有效的规范代表。

加一保持正数位串的 `One`，也保持所有规范位串的 `Canonical`。所以 `toBin` 的每个结果都规范。`onePositive` 证明正数位串的数值至少为一。这个前提很重要：把零翻倍，与给规定的零表示再追加一个零，会得到不同位串。

`toDoublePositive` 证明正自然数所需的翻倍定律。`oneRoundTrip` 用它把转换移过追加的数字，再用归纳假设处理前缀。`canonicalRoundTrip` 加上零情形，补齐 [Induction](Induction.md#binary-laws) 中反方向往返缺少的准确前提。最后，`oneUnique` 与 `canonicalUnique` 证明同一个有效位串的相应谓词证据唯一。后续会利用这个事实证明整个依赖对相等，而不仅仅是其中的位串相等。

## 容易混淆的地方 {#pitfalls}

序关系的“可比性”表示任意两者可比较；函数的“全定义”表示覆盖所有输入并终止。这是不同概念。反对称不是对称：两个方向的不等式一起成立，才迫使相等。推导反演由索引保证，而不是随意挑选模式。规范性也不是“这个位串有数值”：每个原始位串都有数值，包括带前导零的位串。

## 习题与已检查解答 {#exercises}

1. **R.1 — 序结构。** 证明传递性和反对称性，并说明不可能的情形。参考 `leTrans`、`leAntisym`。
2. **R.2 — 单调性。** 推导加法和乘法单调性。参考 `addMono`、`mulMono`，说明乘法证明在哪里使用加法。
3. **R.3 — 严格顺序。** 证明传递性、非自反性及严格加法单调性。参考 `ltTrans`、`ltIrreflexive`、`ltAddMono`。
4. **R.4 — 奇数加奇数。** 完成互相递归的奇偶证明。参考 `evenPlusOdd`、`oddPlusOdd`。
5. **R.5 — 二进制谓词。** 定义首位为一与规范证据，证明加一保持规范性，并证明规范往返。参考 `One`、`Canonical`、`canonicalInc`、`canonicalTo`、`canonicalRoundTrip`。
6. **R.6 — 证据唯一。** 证明同一位串的两份规范性证据相等。参考 `oneUnique`、`canonicalUnique`。
