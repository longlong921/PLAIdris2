# Dedication

For the reader who has asked, “Why is this program right?”—and for the teacher who makes room for that question.

A proof is easier to approach when we can see its small steps. This book is an invitation to take those steps, to try an example, to make a plausible mistake, and to find exactly which premise is missing.

This is a new dedication for an independent Idris2 adaptation. It is not a statement on behalf of the authors of *Programming Language Foundations in Agda*.

## A first promise {#promise}

You do not need to understand a whole proof at once. Start with its type: what is given, and what must be returned? Then examine one constructor or one case. The next page explains how those local questions grow into a theory of programming languages.
